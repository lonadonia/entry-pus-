⚙️ Bot Behavior

Submission limits and human-like timing

Auto Submit After Generation
When enabled, designs are submitted automatically once generation finishes. Disable to review on the Dashboard before clicking Run Submissions.
Disabled
⚠️ Auto-submit is disabled. After generation, open the Dashboard and click Run Submissions to submit manually.
Designs Per Contest
Variations to generate (1–5). Each variation is one image billed by the image provider chosen on the AI Agents page.
💳 3 paid image(s) per contest (3 variations, rendered in parallel)
AI Art Director
An AI art director rewrites each variation's prompt into a vivid, craft-focused brief before generation (composition, typography, color, lighting).
Design Critic
Scores every generated design against the brief; the highest-scoring design is the one submitted.
Skip Contests That Forbid AI
A brief that rules out AI-generated work ("no AI", "AI entries will be disqualified") is skipped before any design is made — every entry this bot submits is declared AI-generated.
Auto-Refine Threshold
If every design scores below this (0–100), one extra corrective design is generated from the critic's feedback. 0 = off. Costs one extra image when triggered.
Max Submissions
Per session (1–20)
Interval Between Entries (minutes)
Wait this long between two contest submissions (default 5). The bot keeps analysing and generating while it waits. 0 = no pause.
AI Use Declaration
Freelancer requires every entry to declare how AI was used, and disqualifies inaccurate declarations. This bot's designs are made by the image model, so "AI generated" is the accurate answer; choose "AI assisted" only if you rework designs yourself before they are submitted. "No AI" is not offered.

🗓 Daily Discovery & Cleanup

Reads the projects published today once a day, at your local time, and sends the eligible ones to analysis. Runs on the server — the dashboard can stay closed. Bids are never submitted automatically.

Checking the scheduler…
Daily Discovery
Run the discovery automatically every day. "Fetch Projects" on the Projects page keeps working either way.
Discovery Time
Wall-clock time in the timezone below (default 23:00 — 11 PM). Only projects published that calendar day — by their real Freelancer publication time, not when they were read — are taken.
Timezone
IANA name (default Africa/Casablanca). Decides both the run time and what "today" means; daylight-saving and Ramadan offset changes are applied automatically from the tz database.
Search Pages to Scan
Newest first, 20 projects per page (default 10 = 200 projects, 1–50). The scan stops early once it reaches yesterday; if the limit runs out first, the run is reported as partial, never as a complete count.
Auto-Delete Skipped / Failed
Remove projects that have been Skipped or Failed for the time below, counted from when they entered that status. A project with any trace of a bid is never deleted; removed ones are kept in an archive and never fetched again.
Delete After (hours)
Default 24 (1–720). The cleanup runs every 15 minutes.
